# Phase 7R.0 experiment register

**Status:** proposals only. None authorizes a model download, dataset acquisition, training run, or production behavior change. Each run should log catalog ID, export/input SHA-256, text-representation version, model/version/cache state, hardware, parameters, candidate limits, and raw judgments. The current comparison baseline is documented in [phase7r-baseline.md](phase7r-baseline.md).

## Recommended sequencing

1. Freeze and reproduce the current 1,000-item v2 baseline with the existing completed Phase 7A judgments; add a documented multi-rater held-out set before interpreting small metric deltas.
2. Run representation-only audits/ablations: field coverage, local/global separation, and source-faithful context descriptions. These directly test known uncertainty without selecting a new model.
3. Evaluate transparent query routing/expansion and structured reranking on the fixed candidate pool.
4. Only after reliable labels, review better embedding models and any task-specific reranker; defer feedback-driven LTR until consented logging and bias controls exist.
5. Treat catalog provenance and quality as a parallel gate, not a downstream cleanup task.

## Minimum experiment record

For every proposal above, store: hypothesis and preregistered decision rule; source/catalog IDs and SHA-256 digests; field map; model identifiers and cache state; hardware; query set and rater protocol; full candidate/rank outputs; latencies; aggregate and per-query metrics; failures; and deviations. Report negative and inconclusive results. Do not replace the production semantic default until an independently held-out evaluation, safety review, and rollback plan support it.
